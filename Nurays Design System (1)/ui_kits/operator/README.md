# Operator UI Kit — Nurays

The admin/operator web app surface. Where a home-food-business owner manages products, vendors, orders, inventory, and reports.

## Files
- `index.html` — interactive click-through (Login → Dashboard)
- `Sidebar.jsx` — fixed left navigation
- `Header.jsx` — sticky translucent top bar
- `StatCard.jsx` — KPI card with gradient top bar
- `PageHeading.jsx` — gradient hero page title
- `ActivityFeed.jsx` — recent activity list
- `QuickActions.jsx` — action grid
- `Login.jsx` — full hero login screen
- `Button.jsx`, `Badge.jsx`, `Input.jsx` — primitives
