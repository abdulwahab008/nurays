## 1. Hub Center Overview

### 1.1 What is a Hub Center?

Hub Centers are micro-fulfillment centers strategically located in high-density areas (DHA, Gulshan, Bahria Town) that serve as:
- **Storage Facilities**: Centralized freezer storage for seller products
- **Quality Control Points**: Pre-delivery quality inspections
- **Fulfillment Centers**: Order packaging and dispatch
- **Pickup Locations**: Customer self-pickup option

### 1.2 Hub Benefits

**For Sellers:**
- No delivery logistics to manage
- Bulk drop-offs (cost-effective)
- Faster order fulfillment
- Quality assurance support

**For Customers:**
- Faster delivery (2-4 hours vs 24 hours)
- Assured quality (hub-checked)
- Self-pickup option (discount)
- Multiple sellers from one hub

**For Platform:**
- Economies of scale
- Quality control
- Lower delivery costs
- Better inventory visibility

## 4. Daily Operations

### 4.1 Morning Routine (8:00 AM - 10:00 AM)

**Opening Checklist:**
- [ ] Unlock hub and check security
- [ ] Check temperature monitoring system
- [ ] Verify freezer temperatures (-18°C or below)
- [ ] Check for any overnight alerts
- [ ] Review pending orders from previous day
- [ ] Check inventory levels (low stock alerts)
- [ ] Brief staff on day's priorities
- [ ] Check equipment (scanners, printers, scales)

**Temperature Check:**
- Target: -18°C to -20°C
- Check: Every 2 hours
- Alert: If >-15°C or <-22°C
- Action: Contact maintenance if alert

### 4.2 Stock Receiving (10:00 AM - 2:00 PM)

**Seller Drop-off Process:**

1. **Seller Arrival:**
   - Seller arrives with products
   - Hub staff greets and verifies seller ID
   - Check appointment (if scheduled)

2. **Product Inspection:**
   - Quality checker inspects products
   - Check packaging integrity
   - Verify expiry dates (minimum 7 days remaining)
   - Check product labels (seller name, product name, batch number)
   - Verify quantity matches seller's claim

3. **Quality Check Criteria:**
   - ✅ Packaging: Intact, no damage
   - ✅ Temperature: Products frozen solid
   - ✅ Expiry: Minimum 7 days remaining
   - ✅ Labeling: Clear, readable, complete
   - ✅ Quantity: Matches seller's claim
   - ✅ Appearance: No visible defects

4. **Acceptance/Rejection:**
   - **Accept**: If all criteria met
   - **Reject**: If any criteria failed (document reason)

5. **Inventory Update:**
   - Scan barcode (or create if none)
   - Enter product details in system
   - Assign storage location (e.g., A1, B2)
   - Update quantity in hub inventory
   - Generate receipt for seller

6. **Storage:**
   - Store products in assigned freezer location
   - Follow FIFO (First In First Out) principle
   - Update physical location in system
   - Label storage unit clearly

**Stock Receiving Form:**
```
Date: ___________
Seller: ___________
Product: ___________
Quantity: ___________
Batch Number: ___________
Expiry Date: ___________
Storage Location: ___________
Quality Check: ✅ Pass / ❌ Fail
Quality Checker: ___________
Notes: ___________
```

### 4.3 Order Fulfillment (10:00 AM - 8:00 PM)

**Order Processing Flow:**

1. **Order Received:**
   - System notification (push/SMS)
   - Order appears in hub dashboard
   - Check order details (items, customer, delivery address)

2. **Inventory Check:**
   - Verify all items available in hub
   - Check expiry dates (minimum 3 days remaining)
   - Reserve items for order
   - If out of stock: Notify seller, customer, operations

3. **Order Preparation:**
   - Pick items from storage (FIFO)
   - Verify items match order
   - Quality check before packaging
   - Package with thermal insulation
   - Add order label with tracking number

4. **Packaging Standards:**
   - Use insulated bags/boxes
   - Add ice packs if needed
   - Seal package securely
   - Attach order label
   - Add handling instructions

5. **Quality Check Before Dispatch:**
   - Verify all items present
   - Check packaging integrity
   - Verify order label
   - Check expiry dates
   - Update order status: "Ready for Dispatch"

6. **Rider Assignment:**
   - Assign available rider
   - Provide delivery address
   - Provide customer contact
   - Provide order details
   - Update order status: "Assigned to Rider"

7. **Dispatch:**
   - Rider picks up order
   - Scan order barcode
   - Verify order details
   - Update status: "Out for Delivery"
   - Provide tracking link to customer

### 4.4 Customer Pickup (10:00 AM - 8:00 PM)

**Self-Pickup Process:**

1. **Customer Arrival:**
   - Customer arrives at hub
   - Provide order number or phone number
   - Staff verifies order in system

2. **Order Retrieval:**
   - Retrieve order from storage
   - Verify order details with customer
   - Quality check (show customer if requested)

3. **Payment (if pending):**
   - Process payment (cash/card)
   - Generate receipt
   - Update payment status

4. **Handover:**
   - Hand over order to customer
   - Provide heating instructions (if needed)
   - Confirm customer satisfaction
   - Update order status: "Picked Up"

5. **Discount Application:**
   - 10% discount for self-pickup
   - Applied automatically in system
   - Refund processed if already paid

### 4.5 Evening Routine (6:00 PM - 8:00 PM)

**Closing Checklist:**
- [ ] Process all pending orders
- [ ] Update inventory levels
- [ ] Check for low stock alerts
- [ ] Review temperature logs
- [ ] Check for expired products
- [ ] Update daily reports
- [ ] Secure hub (lock freezers, doors)
- [ ] Set alarm system
- [ ] Brief next day's priorities

## 5. Inventory Management

### 5.1 Inventory Tracking

**Real-Time Inventory:**
- System shows current stock levels
- Updates automatically on stock in/out
- Alerts when stock low (<20 units)
- Tracks by product, seller, batch

**Physical Inventory:**
- Daily spot checks (random products)
- Weekly full inventory count
- Monthly comprehensive audit
- Discrepancy investigation

**FIFO (First In First Out):**
- Oldest stock used first
- Prevents expiry issues
- Storage organized by date
- System tracks batch dates

### 5.2 Stock Adjustments

**Adjustment Reasons:**
- Damaged products
- Expired products
- Theft/loss
- Quality issues
- System errors

**Adjustment Process:**
1. Identify discrepancy
2. Document reason
3. Take photos (if damaged)
4. Update inventory system
5. Notify seller (if significant)
6. Report to operations team

**Adjustment Form:**
```
Date: ___________
Product: ___________
Batch Number: ___________
Quantity Adjusted: ___________
Reason: ___________
Photos: ___________
Approved By: ___________
```

### 5.3 Expiry Management

**Expiry Tracking:**
- System tracks expiry dates
- Alerts 7 days before expiry
- Alerts 3 days before expiry
- Alerts 1 day before expiry

**Expiry Actions:**
- 7 days: Notify seller to collect or discount
- 3 days: Mark for discount sale
- 1 day: Remove from sale, prepare for disposal
- Expired: Remove from inventory, dispose

**Disposal Process:**
1. Remove expired products
2. Document disposal
3. Take photos (for records)
4. Dispose according to food safety guidelines
5. Update inventory system
6. Report to operations team

### 5.4 Low Stock Alerts

**Alert Thresholds:**
- Low stock: <20 units
- Critical stock: <10 units
- Out of stock: 0 units

**Alert Actions:**
- Notify seller immediately
- Update product availability in system
- Mark as "Low Stock" on product page
- Request restock from seller

## 6. Quality Control

### 6.1 Incoming Quality Check

**Checklist:**
- [ ] Packaging intact
- [ ] Products frozen solid
- [ ] Expiry date valid (7+ days)
- [ ] Labels clear and complete
- [ ] Quantity matches
- [ ] No visible defects
- [ ] Temperature appropriate

**Quality Standards:**
- Packaging: No tears, holes, or damage
- Temperature: Products must be frozen solid
- Expiry: Minimum 7 days remaining
- Labeling: Seller name, product name, batch number, expiry date
- Appearance: No discoloration, freezer burn, or defects

**Rejection Criteria:**
- Damaged packaging
- Thawed or partially thawed products
- Expired or near-expiry (<7 days)
- Missing or unclear labels
- Visible quality issues
- Incorrect quantity

### 6.2 Pre-Dispatch Quality Check

**Checklist:**
- [ ] All items present
- [ ] Items match order
- [ ] Packaging intact
- [ ] Expiry dates valid (3+ days)
- [ ] Thermal insulation adequate
- [ ] Order label attached
- [ ] Ready for delivery

**Quality Standards:**
- All items: Present and correct
- Packaging: Intact, sealed
- Expiry: Minimum 3 days remaining
- Insulation: Adequate for delivery time
- Labeling: Clear order label

### 6.3 Quality Issues Handling

**Customer Complaints:**
1. Receive complaint (phone/email/app)
2. Document complaint details
3. Investigate (check inventory, photos)
4. Resolve (refund/replacement)
5. Report to operations team
6. Follow up with customer

**Seller Quality Issues:**
1. Identify recurring quality issues
2. Document with photos
3. Notify seller
4. Request improvement
5. Escalate if no improvement
6. Consider suspension if severe

## 7. Temperature Monitoring

### 7.1 Temperature Requirements

**Target Temperature:**
- Freezer: -18°C to -20°C
- Acceptable range: -15°C to -22°C
- Critical: >-15°C or <-22°C

**Monitoring:**
- Continuous monitoring (IoT sensors)
- Manual checks every 2 hours
- Log all temperature readings
- Alert on temperature deviations

### 7.2 Temperature Alerts

**Alert Levels:**
- **Warning**: Temperature outside target range but acceptable
- **Critical**: Temperature in critical range
- **Emergency**: Temperature >-10°C (products at risk)

**Alert Actions:**
- Warning: Monitor closely, check equipment
- Critical: Investigate immediately, contact maintenance
- Emergency: Move products to backup freezer, contact operations

### 7.3 Temperature Logging

**Log Requirements:**
- Time: Every 2 hours
- Location: Each freezer unit
- Temperature: Recorded value
- Action: Any corrective actions
- Sign: Staff member initial

**Temperature Log Form:**
```
Date: ___________
Time: ___________
Freezer Unit: ___________
Temperature: ___________
Status: ✅ Normal / ⚠️ Warning / 🚨 Critical
Action Taken: ___________
Staff: ___________
```

## 11. Emergency Procedures

### 11.1 Power Outage

**Procedure:**
1. Check backup generator (if available)
2. If no generator: Contact operations immediately
3. Monitor temperature closely
4. Move critical products to backup location if needed
5. Document outage duration
6. Assess product quality after power restored

### 11.2 Temperature Failure

**Procedure:**
1. Identify affected freezer unit
2. Move products to backup freezer
3. Contact maintenance immediately
4. Document temperature readings
5. Assess product quality
6. Dispose of compromised products
7. Report to operations

### 11.3 Security Incident

**Procedure:**
1. Secure hub immediately
2. Contact security/police if needed
3. Document incident (photos, details)
4. Notify operations team
5. Preserve evidence
6. File incident report

### 11.4 Product Contamination

**Procedure:**
1. Isolate affected products immediately
2. Document with photos
3. Notify operations team
4. Notify seller
5. Dispose of contaminated products
6. Clean and sanitize affected area
7. Investigate root cause
